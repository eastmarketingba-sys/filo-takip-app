Filo Takip — Setup Guide

Prepared for New Hotel  |  4 computers  |  Version 1.8.0

Filo Takip ("Fleet Tracking") is a Windows desktop application for managing your rental vehicle fleet — vehicles, daily overview, documents, appointments, analytics, and customers. It stores data locally on each computer and includes automatic update checks. The interface is available in Turkish, English, and Bosnian (switch anytime via the 🌐 button, top right).

1. Download

Download the installer on each of the 4 computers:

Download Filo Takip Setup (.exe)

Direct link: https://github.com/eastmarketingba-sys/Filo-takip/releases/download/v1.8.0/Filo-Takip-Setup-1.8.0.exe

2. Install

  1. Run the downloaded Filo-Takip-Setup-1.8.0.exe.
  2. Choose an install location (or keep the default) and finish the wizard.
  3. A desktop shortcut is created automatically.
  4. Launch Filo Takip.

3. Activate

On first launch, the app will ask for an activation code. An internet connection is required at this step. Use one code per computer — each code below is valid for exactly one machine and locks to it once entered.

If a computer is later replaced, reformatted, or a code was mistyped into the wrong machine, contact us and we'll reset that code so it can be re-activated on the correct computer.

4. Updates

Filo Takip checks for updates automatically. You can also check manually any time from the profile menu (top right) → Güncelle / Update.
